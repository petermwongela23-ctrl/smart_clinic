# Smart Clinic Management System

An advanced clinic management system featuring live queue tracking, automated appointment scheduling, doctor workload balancing, and bilingual (English/Kiswahili) support.

## Prerequisites
- [XAMPP](https://www.apachefriends.org/) (or any PHP/MySQL local server environment)

## Setup Instructions
1. Clone or download this repository into your local server root folder (e.g., `htdocs` in XAMPP).
2. Start **Apache** and **MySQL** from your XAMPP Control Panel.
3. Open `http://localhost/phpmyadmin`.
4. Create a new database named `smart_clinic` and import the provided database file (`database/smart_clinic.sql`).
5. Open your browser and navigate to: `http://localhost/smart_clinic/`
